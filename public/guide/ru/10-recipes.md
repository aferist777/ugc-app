# Рецепты

Целые пути от идеи до готового видео, шаг — строка. Каждый шаг ведёт к главе, где он рассказан полностью.

## Реклама: говорящая голова с вашим товаром

1. **Человек** — Библиотека → Персонажи → **Новый персонаж** или уже имеющийся ([Персонажи](03-the-library.md#персонажи)).
2. **Товар** — КАРТИНКИ → Предметы → **Создать**: его фото, название, несколько слов ([Новый предмет](08-generating.md#окружения-лукбуки-и-предметы)).
3. **Место** — КАРТИНКИ → Окружения → **Создать** по фото и фразе или уже сделанное раньше.
4. **Сценарий** — Библиотека → Сценарии → **Новый сценарий**: напишите его — по реплике на абзац, хук первым — или пусть
   его напишет генератор рассказчика ([Сценарии](03-the-library.md#сценарии)). **Сделать видео** открывает его в Монтаже.
5. **Кто и где** — образ и окружение ([Кто и где](05-talking-head.md#кто-и-где)).
6. **Настроение и голос** → **сгенерировать**: озвучивается каждая реплика.
7. **Чат кадров** — попросите кадры: «крупный план, она подносит флакон с дозатором к камере»; положите товар в зону
   **товар · из Предметов**; **в кадры** кладёт кадр в набор ([Кадры](05-talking-head.md#2-кадры)).
8. **Видео** → **сгенерировать**, затем **… · запустить?** — клип для каждой реплики ([Видео](05-talking-head.md#3-видео)).
9. На таймлайне: **Субтитры** → пресет — слова реплик распознаются сами ([Субтитры](04-merge.md#субтитры)).
   Если хотите, добавьте B-roll и музыку (рецепты ниже), потом **Экспорт** → **Рендерить**.

## Озвучка поверх стоковых кадров

1. **Главная → Озвучка**: сценарий или ваш текст, настроение, голос → **Создать** ([Как начать](06-voiceover.md#как-начать)).
2. **сгенерировать** — сценарий озвучивается.
3. **найти B-roll** — видео для каждой фразы ложатся поверх голоса ([B-roll](06-voiceover.md#2-b-roll)).
4. Нажмите на кусок, который не подходит, и выберите другой из найденного ([Замена куска](06-voiceover.md#замена-куска)).
5. **Субтитры** → пресет — слова уже распознаны, для B-roll.
6. **Экспорт** → **Рендерить**.

## Шортсы из подкаста или интервью

1. **Главная → Нарезка**: видео — ссылка, Библиотека или файл ([Шаг 1](07-highlights.md#шаг-1-видео-и-фрагменты)).
2. **Подкаст · интервью**, длина (30–60 с — хорошее начало), сколько → **Далее →**.
3. Настроения музыки и пресет субтитров → **Найти моменты** ([Шаг 2](07-highlights.md#шаг-2-музыка-и-субтитры)).
4. Когда плитки появятся: нажмите на каждую, чтобы посмотреть её; удалите слабые (✕), переименуйте хорошие.
5. **Выбрать всё** → поменяйте общее четырьмя кнопками **· для всех N** ([Несколько фрагментов сразу](07-highlights.md#несколько-фрагментов-сразу)).
6. **Рендерить N** — каждый шортс в папке рендеров проекта.

## Клип B-roll из картинки

1. **КАРТИНКИ → Создать** — чат картинок: опишите картинку, формат 9:16 ([Чат картинок](08-generating.md#чат-картинок)).
2. Правая кнопка на сделанной картинке (в Библиотеке или на таймлайне) → **Оживить…** — открывается чат видео с ней как
   с первым кадром.
3. Дешёвая модель для пробы — **Seedance 2.0 mini** или **Grok**, — фраза о том, что движется → отправить; с включённым
   автором промпта посмотрите его промпт и нажмите **Сделать видео** ([Чат видео](08-generating.md#чат-видео)).
4. Перетащите клип на видеодорожку над основным видео — вставка поверх говорящего.

## Музыка, написанная для видео

1. На таймлайне правая кнопка на клипе → **Видео в музыку…** — открывается окно звука с этим клипом.
2. Если хотите, скажите настроение → **Сгенерировать**: трек ляжет на отдельную звуковую дорожку под клипом
   ([Окно звука](08-generating.md#окно-звука)).
3. Или **ЗВУК → Создать** → **Простой** — фоновая музыка без голоса, её длина «по видео».
4. Сделайте музыку тише на её дорожке, чтобы голос звучал поверх неё.

## Своя запись: паузы убрать, субтитры добавить

1. **+ Новый проект → пустой**; перетащите видеофайл из Проводника на основное видео — он скопируется в ВИДЕО → Загрузки.
2. Проведите по всей волне, затем **S** — **Убрать тишину** укорачивает все паузы сразу ([Убрать тишину](04-merge.md#убрать-тишину)).
3. Дорожка «Субтитры» → **Сгенерировать по звуку**; если слово распознано неверно, поправьте его в **Субтитры → Текст**.
4. **Субтитры** → пресет; перетащите субтитры на превью туда, где они должны стоять.
5. **Экспорт** → **Рендерить**.

## Кусок длинного видео

1. Библиотека → Медиа → **По ссылке** (или **Загрузить**) — видео ляжет в открытую папку.
2. Откройте его: проведите по полосе под ним, чтобы нарисовать фрагменты, или нажмите **Сцены**, чтобы найти планы ([Просмотр](03-the-library.md#просмотр-и-как-резать-видео)).
3. **▶** проигрывает их подряд; **Сохранить…** склеивает их в один новый клип рядом с видео.
4. Перетащите клип на таймлайн.

## С телефона

1. Отправьте своему боту в Telegram ссылку на пост, фото или видео ([РЕФЕРЕНСЫ](03-the-library.md#референсы-и-бот-telegram)).
2. Пост приходит в **РЕФЕРЕНСЫ** — по плитке на пост. Откройте его; вырежьте кусок, как выше, или прикрепите его
   картинки в чате как референсы.
