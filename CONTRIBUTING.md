# Contributing

Thank you for wanting to help.

**Pull requests are not accepted for now.** UGC Studio is made by one person, and every change goes through its own
plan and checks; a pull request would wait without an answer. What helps most:

- **Found a bug?** Open an [Issue](https://github.com/aferist777/ugc-app/issues/new/choose) with the version (Admin →
  This computer), what you did, what you expected and what happened. The app's log is `logs/app.log` inside your
  library folder — attach the lines around the moment it went wrong. **Never paste API keys** — the log has none, but a
  screenshot of Admin → API keys might.
- **An idea or a question?** Start a [Discussion](https://github.com/aferist777/ugc-app/discussions).
- **A security problem?** Do not open a public Issue — see [SECURITY.md](SECURITY.md).

Every message is read; an answer or a fix is not promised.
