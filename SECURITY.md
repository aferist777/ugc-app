# Security

UGC Studio runs on your own computer: its server listens only on 127.0.0.1, it has no account or sign-in, and your API
keys stay in your library folder and go only to their own services.

If you find a way around that — a key leaving the computer, a page or file reachable from outside, a link or file that
makes the app do something it should not — **please do not open a public Issue**. Write to
**workingbeast13@gmail.com** with what you found and how to repeat it. You will get an answer, and the fix will go out
in an update before the problem is made public.

Only the latest version is fixed; the app updates itself.
